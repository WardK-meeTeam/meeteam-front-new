# 팀원 찾기 E2E 시나리오

## 목표

- 팀원 찾기 화면에서 사용자가 원하는 팀원을 탐색하는 핵심 흐름을 UI 기준으로 검증한다.
- 검색, 필터, 정렬, 추가 로딩, 빈 결과 상태가 서로 충돌 없이 동작하는지 확인한다.

## 시나리오

### 1. 기본 진입과 초기 정렬

- 사용자가 `/teammates` 페이지에 진입하면 제목과 총 인원 수가 보인다.
- 초기 목록은 프로젝트 경험 많은 순으로 정렬된다.
- 첫 화면에는 초기 노출 개수인 15명만 보인다.

### 2. 이름, 분야, 기술 스택 복합 필터

- 사용자가 이름을 입력해 후보를 줄인다.
- 분야 필터를 눌러 역할을 좁힌다.
- 기술 스택 키워드를 입력해 최종 후보를 1명으로 압축한다.
- 결과 카드가 기대한 팀원과 일치하는지 확인한다.

### 3. 정렬 변경

- 사용자가 정렬을 이름순으로 바꾸면 목록 순서가 한글 이름 오름차순으로 바뀐다.
- 정렬 변경 후에도 총 결과 수는 유지된다.

### 4. 무한 스크롤 추가 로딩

- 사용자가 목록 하단까지 내려가면 추가 카드가 로딩된다.
- 15명에서 20명으로 늘어나고, 다시 하단에 도달하면 최종 24명까지 노출된다.
- 모든 팀원을 다 불러오면 더 이상 로딩 트리거가 나타나지 않는다.

### 5. 결과 없음 상태

- 사용자가 존재하지 않는 이름 또는 기술 스택으로 검색하면 결과가 0명이 된다.
- 빈 상태 문구가 노출되고, 카드 목록은 렌더링되지 않는다.
