# 프로젝트 찾기 E2E 시나리오

## 목표

- 프로젝트 찾기 화면에서 사용자가 원하는 프로젝트를 탐색하는 핵심 흐름을 UI 기준으로 검증한다.
- 검색, 카테고리, 모집 상태, 플랫폼, 분야, 정렬, 추가 로딩, 빈 상태와 필터 초기화가 충돌 없이 동작하는지 확인한다.

## 시나리오

### 1. 기본 진입과 최신순 정렬

- 사용자가 `/projects` 페이지에 진입하면 제목과 총 프로젝트 수가 보인다.
- 초기 목록은 최신 생성일 순으로 정렬된다.
- 첫 화면에는 초기 노출 개수인 8개 프로젝트만 보인다.

### 2. 검색과 모든 필터를 조합한 결과 좁히기

- 사용자가 리더 이름으로 검색한다.
- 카테고리, 모집 상태, 플랫폼, 분야 필터를 함께 적용한다.
- 복합 조건을 모두 만족하는 프로젝트가 1개로 좁혀지는지 확인한다.

### 3. 정렬 변경

- 사용자가 정렬을 마감임박순으로 바꾸면 모집 마감일이 가장 빠른 프로젝트가 먼저 보인다.
- 마감일이 같은 프로젝트는 기존 최신순 기반 순서가 유지되는지 함께 확인한다.

### 4. 무한 스크롤 추가 로딩

- 사용자가 목록 하단까지 내려가면 추가 카드가 로딩된다.
- 8개에서 12개로 늘어나고, 모든 프로젝트를 불러오면 더 이상 로딩 트리거가 나타나지 않는다.

### 5. 결과 없음 상태와 필터 초기화

- 사용자가 존재하지 않는 검색어와 필터 조합을 적용하면 결과가 0개가 된다.
- 빈 상태 문구와 필터 초기화 버튼이 노출된다.
- 초기화 버튼을 누르면 기본 목록과 기본 필터 상태로 돌아온다.
