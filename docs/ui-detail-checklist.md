# UI 세부점검 체크리스트

## 목적

구현 완료 후 Figma 대비 UI 정합성을 빠르게 검증하기 위한 점검 단계입니다.

## 1. 레이아웃

- 주요 컨테이너 폭/높이가 Figma와 일치하는지 확인
- 좌우 컬럼 비율, 카드 간격, 섹션 패딩 값 확인
- 모바일/태블릿/데스크톱 브레이크포인트에서 레이아웃 깨짐 여부 확인

## 2. 타이포

- 제목/본문/보조 텍스트의 크기, 두께, 줄간격 확인
- 텍스트 줄바꿈 위치(특히 카드 제목) 확인
- 강조 텍스트(배지, 라벨) 대비 확인

## 3. 색상/토큰

- 하드코딩 색상 없이 프로젝트 토큰 클래스만 사용했는지 확인
- 상태 색상(활성/비활성/보더/배경) 일치 여부 확인
- 투명도 및 오버레이(blur 포함) 강도 확인

## 4. 아이콘

- 모든 아이콘이 lucide-react 기반인지 확인
- Figma 아이콘 의미와 동일한지 확인
- 아이콘 크기/두께가 주변 텍스트와 조화로운지 확인

## 5. 인터랙션

- hover/focus/active 스타일 확인
- 링크 외부 이동 target/rel 속성 확인
- 버튼 disabled 상태가 필요한 경우 시각적으로 구분되는지 확인

## 6. 이미지/에셋

- 이미지 비율 유지(object-fit) 및 잘림 의도 확인
- 외부 임시 localhost 자산 사용 여부 확인
- 배포용으로 public 또는 CDN 경로 치환 필요 여부 확인

## 7. 접근성

- 아이콘 버튼에 의미 있는 레이블이 필요한지 확인
- 텍스트 대비(명도) 최소 기준 충족 여부 확인
- 키보드 탐색 시 포커스 이동이 자연스러운지 확인

## 8. 최종 검증

- Figma 캡처와 나란히 비교 후 차이 목록 작성
- 차이 항목 우선순위 지정(필수/권장/보류)
- 머지 전 최종 스크린샷(Desktop/Mobile) 저장
